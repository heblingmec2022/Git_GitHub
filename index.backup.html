Merge (clone, fetch) e conflitos - Intermediário

  1. Como unir alterações de diferentes branches
  2. Comandos: git merge, git rebase, git checkout -b "nome da func"
  3. Comandos: git clone "url do repositório" (fazer a clonagem num pasta independente para continuar o trabalho)
  4. Comando git fetch (baixa os arquivos do projeto sem fazer o merge). Após esse comando, é possível visualizar as alterações e decidir se deseja integrá-las com git rebase.
  5. Comando: git pull é uma junção do merge com rebase (para pegar o novo arquivo da pasta principal e levar para a clonada)
  6. Comandos: git push, git tag, e atribuições a novos usuários no projeto

06

Git Avançado

  1. Criando novo repositório no GitHub.
  2. Comando: git remote add origin "url do repositório", git remote -v
  3. Comando: git push -u origin main
  4. Usando git config credential.helper store (para armazenar credenciais no repositório atual).
  5. Comandos: git revert, git reset, git reflog, git clean
  6. Como usar tags para marcar versões importantes do projeto
  7. Comando: git tag -a v1.0 -m "mensagem da tag"
  8. Comando: Usando git push para testar colaboradores externos incluídos no projeto principal.
  9. Comando: git checkout -- . (desfaz alterações locais em todos os arquivos), git checkout "nome do arquivo"
  10. Comando: git revert "hash do commit" (desfaz alterações de um commit específico)
  11. Comando: git reset HEAD "nome do arquivo" (desfaz alterações locais em um arquivo específico), ou git reset --soft ou --mixed ou --hard HEAD~1
